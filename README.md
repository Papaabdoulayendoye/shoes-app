## 📌 About

**Shoes App** is a **mobile-first e-commerce demo** for sneaker lovers.  
Built with **React-Native**, **Expo** and **Sanity CMS**, it showcases :

- Browse sneakers by brand / collection  
- Add items to cart  
- Checkout flow ( Stripe-ready hooks )  
- Admin panel via Sanity Studio to add / edit products  

&gt; Academic project – part of my **Master TNSID** – open-source & internship-ready.

---

## 🧪 Tech Stack

| Layer        | Technologies                                                            |
|--------------|-------------------------------------------------------------------------|
| **Mobile**   | ReactJS, TypeScript, Tailwind-Native                                    |
| **State**    | Zustand (lightweight cart store)                                        |
| **Media**    | Sanity Image CDN – auto WebP / responsive                               |
| **Nav**      | Expo Router v2 – file-based routing                                     |
| **Build**    | EAS Build / Vercel (Sanity Studio)                                      |

## ✨ Key Features

- 🎯 **Home screen** : hero carousel, summer collection, stats counter  
- 🔍 **Product list** : filter by brand, price, size  
- 📱 **iOS & Android** via Expo Go or EAS build
